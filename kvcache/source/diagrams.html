Move It Down, Not Out
KV offload keeps evicted cache in cheaper, larger memory instead of deleting it.
GPU memory
Tens of gigabytes. Fastest, and where attention runs.
↓ offload when idle↑ load back on a hit
CPU memory
Hundreds of gigabytes per server. Slower to reach.
↓ offload when idle↑ load back on a hit
Local disk or shared storage
Terabytes. Slowest, but survives restarts.
vLLM can offload evicted blocks to CPU memory natively. LMCache adds disk and shared storage tiers. Capacities are typical orders of magnitude.
A load from CPU memory beats a 3,000 token prefill.
